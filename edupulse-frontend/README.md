# EduPulse AI Frontend

React frontend for the EduPulse AI student feedback intelligence system.

## Stack

- React + TypeScript
- Vite
- Recharts for dashboard charts
- Lucide React for icons

## Run Locally

Start the backend first on port `4000`, then run:

```bash
npm install
npm run dev
```

Frontend URL:

```text
http://127.0.0.1:5173
```

## Current Features

- Student/admin login
- Student semester feedback form
- Conditional issue text box for low ratings
- Live grievance form with anonymous option
- Admin dashboard metrics
- Category satisfaction bar chart
- Grievance severity chart
- Analysis generation
- Report history and detail view
- PDF report download
